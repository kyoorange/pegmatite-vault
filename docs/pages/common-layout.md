# 共通レイアウト

```text
┌─────────────────────────────────────────────────────────┐
│ PEGMATITE VAULT                       [＋ 標本を追加]   │
├────────────┬────────────────────────────────────────────┤
│ HOME       │ ページタイトル                             │
│ VAULT      │                                            │
│ LIBRARY    │ ページコンテンツ                           │
│ ADMIN      │                                            │
│ SETTING    │                                            │
├────────────┴────────────────────────────────────────────┤
│ VERSION / STORAGE STATUS                                │
└─────────────────────────────────────────────────────────┘
```

- ヘッダー: アプリ名、ページ名、標本追加ボタン。
- サイドメニュー: HOME、VAULT、LIBRARY、ADMIN、SETTING。選択中の項目を強調する。
- フッター: バージョンと画像ストレージ状態。
- 狭い画面ではサイドメニューをドロワーへ切り替える。
- 読み込み中はスケルトン、空状態は次の操作、APIエラーは再試行を表示する。
- 保存中は二重送信を防止し、削除時は対象名を含む確認を表示する。
- キーボード操作、可視フォーカス、アイコンのアクセシブル名を保証する。
