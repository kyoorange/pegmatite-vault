# HOME

お気に入りと最近追加した標本への入口。

```text
┌ HOME ───────────────────────────── [＋ 標本を追加] ┐
│ お気に入り                            [すべて見る] │
│ [画像 No.001 標本名] [画像 No.014 標本名]         │
│ 最近追加した標本                      [すべて見る] │
│ [画像 No.027 標本名] [画像 No.031 標本名]         │
└────────────────────────────────────────────────────┘
```

- 各セクションを最大6件表示する。
- カードに代表サムネイル、番号、名称、主な鉱物、採集地を表示する。
- カードから標本詳細、「すべて見る」から条件付きVAULTへ移動する。
- 対象がない場合は標本登録への導線を表示する。
