# 標本登録・編集

```text
┌ 標本を登録 ─────────────────────────────────────┐
│ 標本番号 [自動採番]  標本名 [______________] * │
│ 採集地 [選択▼]       入手経路 [選択▼]          │
│ 入手日 [____-__-__]  お気に入り [ ]            │
│ 鉱物 [検索・複数選択________________]           │
│ 特徴 [____________________________________]     │
│ 備考 [____________________________________]     │
│ 画像 [選択] [画像1 並替 削除] [画像2 ...]       │
│                           [キャンセル] [保存]   │
└─────────────────────────────────────────────────┘
```

- 標本名は必須。採集地、入手経路、鉱物は未設定を許可する。
- 番号未指定時はAPIが同じ採集地の最大値＋1を割り当てる。
- 鉱物は複数選択できる。
- JPEG、PNG、WebPの形式とサイズを検証する。
- 画像は並べ替えでき、先頭を代表画像とする。
- 項目付近に入力エラーを表示し、未保存離脱時は確認する。
