# LIBRARY

```text
┌ LIBRARY ─────────────────────────────────────────┐
│ [鉱物名を検索____________] [名称順▼]             │
│ [すべて] [元素] [硫化] [酸化] ...                │
│ 石英 / Quartz    SiO₂    三方晶系    標本12件    │
│ 黄鉄鉱 / Pyrite  FeS₂    立方晶系    標本8件     │
└───────────────────────────────────────────────────┘
```

- 和名、英名、化学式を検索し、鉱物分類で絞り込む。
- 名称または関連標本数で並び替える。
- 和名、英名、化学式、結晶系、分類、関連標本数を表示する。
- 項目から鉱物詳細へ移動する。
