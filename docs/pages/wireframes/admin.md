# ADMIN

```text
┌ ADMIN ──────────────────────────────────────────┐
│ [鉱物種 123件] [鉱物分類 10件]                  │
│ [採集地  42件] [入手経路  4件]                  │
├ 鉱物種 ──────────────────────── [＋ 新規登録] ┤
│ [検索________]                                  │
│ 石英  Quartz  酸化鉱物              [編集][削除]│
└─────────────────────────────────────────────────┘
```

- 鉱物種、鉱物分類、採集地、入手経路を管理する。
- 各対象に一覧、検索、登録、編集、削除を提供する。
- 共通の一覧・フォーム枠を再利用する。
- 使用中マスタの削除を拒否し、理由を表示する。
