# 採集地詳細

```text
┌ ○○鉱山 ────────────────────────────────────────┐
│ 通称: △△坑  緯度・経度: 00.0000000, 000.0000000│
│ 備考: ________________________________________  │
│ 関連標本 8件                                    │
│ [画像 No.001 標本名] [画像 No.027 標本名]       │
└──────────────────────────────────────────────────┘
```

- 地名、通称、緯度、経度、備考を表示する。
- 座標がそろっている場合だけ地図への外部リンクを表示する。
- 関連標本をページングし、カードから標本詳細へ移動する。
