# SETTING

```text
┌ SETTING ────────────────────────────────────────┐
│ バージョン / DB状態                             │
│ 画像保存先 / 書き込み状態 / 使用量              │
│ [保存先を変更]                                  │
│ [CSV出力] [CSV取込] [バックアップ] [リストア]   │
│ [アーカイブ画像を管理]                          │
└─────────────────────────────────────────────────┘
```

- アプリ、DB、画像ストレージの状態を表示する。
- 保存先変更はコピーと整合性確認後に切り替え、旧ファイルを自動削除しない。
- CSV取込は検証結果を表示してから確定する。
- アーカイブ画像の復元と完全削除を提供する。
- 完全削除やリストアは、影響を示して再確認する。
