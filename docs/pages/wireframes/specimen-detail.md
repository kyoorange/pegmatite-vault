# 標本詳細

```text
┌ 標本 No.001 ───────────────────── [編集] [削除] ┐
│ [            メイン画像            ]  標本名     │
│ [小][小][小]                          ☆お気に入り │
│ 鉱物 / 採集地 / 入手経路 / 入手日                │
│ 特徴 / 備考                                       │
└───────────────────────────────────────────────────┘
```

- `sort_order` が最小の画像をメイン表示する。
- サムネイルで画像を切り替え、メイン画像から拡大表示する。
- 鉱物名と採集地名から各詳細へ移動する。
- 編集から標本フォームへ移動する。
- 削除確認後に標本を削除し、画像を論理アーカイブする。
