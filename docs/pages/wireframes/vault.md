# VAULT

所有標本の検索、絞り込み、並び替えを行う。

```text
┌ VAULT ──────────────────────────── [＋ 標本を追加] ┐
│ [キーワード____________] [鉱物▼] [採集地▼] [☆]   │
│ 24件                 [新しい順▼] [グリッド|一覧]  │
│ [画像 No.001 標本名] [画像 No.014 標本名]         │
│                  [前へ] 1 / 3 [次へ]               │
└────────────────────────────────────────────────────┘
```

- 標本番号、標本名、鉱物名、採集地名を検索する。
- 鉱物、採集地、お気に入りで絞り込む。
- 作成日時、標本番号、標本名で並び替える。
- 検索条件、表示形式、ページをURLクエリに保持する。
- カードまたは行から標本詳細へ移動する。
